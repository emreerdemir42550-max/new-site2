How to read this table

“Runs with” names the actual browser primitives and libraries the tool uses. If a tool needed a server, it would be listed here as a network call — none of the twenty do. The three categories exist because PDF page trees, raster pixels and colour sampling fail in different ways, not because the marketing needed three columns.

  • PDF documents — Assemble, split, rotate, watermark and inspect PDFs. The page tree is rewritten with PDF-lib inside the tab, so nothing is uploaded and no queue exists.
  • Images & metadata — Resize, crop, convert, compress and strip metadata from JPG, PNG and WebP using Canvas and an in-tab EXIF parser.
  • Color & palettes — Read exact pixel values, extract a usable palette and export swatches for design handoff.
