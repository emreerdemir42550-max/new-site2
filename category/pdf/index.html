PDF · 12 tools

PDF documents

PDF work is mostly page-tree surgery: which pages exist, in what order, and how each page is drawn. These tools read the file into memory, rewrite the object graph, and hand the result back as a download.

01 Merge PDF Combine several PDFs into one file, in the exact order you choose. PDF-lib → 02 Split PDF Split one PDF into separate documents by page range or one page per file. PDF-lib → 03 Extract PDF Pages Copy selected pages from a PDF into a new, smaller document. PDF-lib → 04 Rotate PDF Pages Rotate every page or a single page by 90, 180 or 270 degrees. PDF-lib → 05 Reorder PDF Pages Rearrange the page order of a PDF with drag or keyboard controls. PDF-lib → 06 Images to PDF Turn JPG, PNG and WebP images into a paginated PDF at the size you choose. Canvas → 07 PDF to Images Render PDF pages to PNG, JPG or WebP at a resolution you control. PDF.js → 08 PDF Text Extractor Pull the text layer out of a PDF, page by page, with an honest warning about scans. PDF.js → 09 PDF Metadata Viewer & Cleaner Inspect a PDF's document information dictionary, then strip the fields you choose. PDF-lib → 10 Add PDF Page Numbers Stamp page numbers onto a PDF with control over position, format and start value. PDF-lib → 11 Add PDF Watermark Stamp diagonal or horizontal text across PDF pages with adjustable opacity. PDF-lib → 12 Compress PDF Re-encode a PDF's images at a lower resolution and quality, with an honest report of what changed. PDF.js →
