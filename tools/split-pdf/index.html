Split PDF

Split one PDF into separate documents by page range or one page per file.

Runs locally in your browser PDF-lib · JSZip · Blob

Splitting happens with PDF-lib in the tab. Output files are assembled as in-memory Blobs and only exist on your disk after you download them.

Loading the local engine…

How it works

  1. Choose one PDF and read the page count.
  2. Pick a mode: ranges or one file per page.
  3. Enter ranges if needed — the tool shows how many files will be produced.
  4. Download the ZIP, or download individual parts.

PDF-lib · JSZip · Blob

Worked example

Separating chapters from a 42-page report

Enter 1-2, 3-18, 19-40, 41-42 to get four files: front matter, chapter one, chapter two and the appendix. The tool previews “4 files” before you run it, so a typo in the range list is caught immediately.

Privacy & limitations

What it does

  • Split by custom ranges such as 1-3, 4, 8-12
  • Split into one file per page
  • Download every result as a single ZIP
  • Range syntax is validated before any work starts

What it will not do

  • Output filenames are derived from the source name and sanitised.
  • A 500-page document produces 500 entries in the ZIP; expect a few seconds of work.

Want to verify the privacy claim yourself? Open DevTools → Network, clear the log, then run this tool. No request carrying your file appears. See the full explanation.

Questions people actually ask

Can I split by bookmarks or a table of contents?

Not currently. Bookmark outlines vary a lot between producers; ranges are predictable and verifiable, so they are the only split mode shipped.

What happens to annotations?

Page annotations travel with their page, because the page object is copied intact. Document-level attachments are not carried over.

Is the ZIP created locally?

Yes. JSZip assembles the archive in the tab from Blobs that already exist in memory.
