Tool index

Twenty tools. One tab. Nothing uploaded.

Every tool here reads your file into browser memory, transforms it with JavaScript, and hands back a download. There is no queue, no account and no server-side copy.

PDF documents

Assemble, split, rotate, watermark and inspect PDFs. The page tree is rewritten with PDF-lib inside the tab, so nothing is uploaded and no queue exists.

Category page →
01 Merge PDF Drag files into order, then merge them into a single PDF. PDF-lib → 02 Split PDF Cut a document into ranges, or explode it into single pages. PDF-lib → 03 Extract PDF Pages Pick the pages you need and drop the rest. PDF-lib → 04 Rotate PDF Pages Fix sideways scans without re-rendering the document. PDF-lib → 05 Reorder PDF Pages Put pages in the right order, with a keyboard path for every move. PDF-lib → 06 Images to PDF One image per page, with page size and margin control. Canvas → 07 PDF to Images Page-by-page raster export with a real DPI control. PDF.js → 08 PDF Text Extractor Extract selectable text; scanned pages are reported as image-only. PDF.js → 09 PDF Metadata Viewer & Cleaner See exactly which metadata fields exist before removing them. PDF-lib → 10 Add PDF Page Numbers Number pages without touching the original layout.
