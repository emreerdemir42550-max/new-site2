Privacy

Privacy, in plain language

PrismFile has no file server, no accounts and no third-party trackers. This page is the short version of what that means in practice.

Your files do not leave your device

Every tool on this site runs in your browser tab. The file you select is read into memory by JavaScript, transformed there, and returned to you as a download. There is no upload endpoint to send it to. The trust center explains the mechanics and how to verify them.

What this site does not do

  • No account, no sign-in, no email capture.
  • No cookie wall, because no cookies are set by the site.
  • No third-party analytics, advertising or session-recording script.
  • No newsletter popup, no exit-intent modal.
  • No file names, file contents, text, colours, dimensions or values sent anywhere.

The only data this site keeps

Seven aggregate event names — tool_open, tool_complete, download_output, copy_output, training_open, training_to_tool, search_tool — are counted in your browser's own localStorage. Nothing is transmitted. Clearing site data deletes the counts. They exist so the site can say “this tool is used” without pretending to have a live global counter.

Hosting

The site is served as static files. Hosting infrastructure necessarily sees ordinary request metadata — IP address, user agent, the page you requested — like every website. What it never sees is your file, because your file is never part of a request.

External links

Some training articles link to standards documents, library documentation and Unsplash photo credits. Following one of those links takes you to another site with its own privacy policy. Images credited to Unsplash are hotlinked from Unsplash's image CDN as their API guidelines require, which means your browser requests the image from them when an article displays it.

Children and sensitive documents

This is a general-purpose utility site with no accounts and no user-generated content. It is not directed at children. Because processing is local, it is also suitable for documents you would not upload elsewhere — but you remain responsible for handling them lawfully.
